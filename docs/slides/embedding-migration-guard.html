Embedding Migration Guard

임베딩 모델 교체 전, CLI 한 줄로 recall@k 드롭을 예측한다

  • 카테고리: RAG / Vector Search 인프라
  • 스택: Python, sentence-transformers, NumPy, Click, uv
  • 날짜: 2026-03-12

Background

임베딩 모델 교체는 RAG의 가장 비싼 작업이다

  • RAG 파이프라인의 핵심은 임베딩 모델. 더 좋은 모델이 나오면 바꾸고 싶다
  • 문제는 모델을 바꾸면 기존 벡터 인덱스 전체를 재구축해야 한다는 것
  • 수백만 문서 코퍼스에서 재인덱싱은 수 시간~수일, 비용은 수백 달러 이상
  • 그래서 대부분의 팀은 모델 업그레이드를 미룬다

2026년 현재, 마이그레이션 전용 도구는 없다

  • LlamaIndex, LangChain 모두 "모델 바꾸면 전체 재인덱싱" 전제
  • 벡터 DB(Qdrant, Pinecone)도 모델 전환 워크플로 미제공
  • "바꿔도 되는지" 미리 검증하는 도구 자체가 부재

Pain Point

커뮤니티에서 반복적으로 나오는 고통

출처SignalPain Point
HN⬤⬤⬤임베딩 모델 업데이트 시 기존 벡터 인덱스 호환이 깨져 RAG 파이프라인 전체가 망가진다
HN⬤⬤⬤대규모 코퍼스에서 모델 교체 = 전체 재구축, 마이그레이션 비용이 막대하다
HN⬤⬤⬤Pinecone 벡터 인덱스가 예기치 않게 깨지는 문제가 반복 발생
Reddit⬤⬤클라우드 임베딩 API 버전 변경 시 수천 건을 전부 재처리해야 한다

공통 패턴: 모델은 바꾸고 싶은데, 바꾸면 뭐가 깨질지 모른다

Solution

교체 전에 예측한다, 교체 후에 후회하지 않게

한 줄 요약: emg check 한 번이면 두 모델 간 recall@k 드롭을 미리 알 수 있다

기존 방식과의 차이

기존 방식EMG
검증 시점교체 후 (사후 확인)교체 전 (사전 예측)
비용전체 재인덱싱 필요샘플 코퍼스로 수 초
판단 기준감, 경험recall@k, NN overlap, cosine 분포
결과물없음JSON 리포트 (CI 연동 가능)

Key Decisions & Lessons

기술 판단

판단선택이유
벡터 DBNumPy in-memory110문서에서 ChromaDB보다 빠르고 단순. 확장 시 교체 가능
CLI 프레임워크Click서브커맨드 구성이 깔끔. argparse보다 선언적
리스크 판정recall@10 + NN overlap 조합단일 메트릭보다 robust. recall만으로는 false positive 많음

심의 피드백

  • 문제 진정성: 4.0/5 — 실제로 커뮤니티에서 반복 제기되는 문제
  • 프로토타입 적합성: 3.3/5 — 검증 목표가 명확하고 범위가 적절
  • 반대 의견: "cosine 분포 비교 + recall 측정은 notebook 수준, Drift-Adapter 같은 비자명한 접근이 빠져 있다"
  • 솔직히 기술적 깊이는 얕은 편. 하지만 문제 정의와 UX에 집중한 프로토타입

Results & Future

성과 (5/5 통과)

  • ✅ emg check으로 벡터 공간 차이 리포트 출력
  • ✅ recall@k 비교 결과 출력 (recall@1, @5, @10)
  • ✅ 100+ 문서에서 30초 이내 완료 (110문서, 7.7초)
  • ✅ JSON export (CI 파이프라인 연동용)
  • ✅ emg demo로 전체 워크플로 시연

한계

  • sentence-transformers 모델만 지원 (OpenAI, Cohere 등 API 모델 미지원)
  • 차원이 다른 모델 간 비교 불가 (projection 미구현)
  • Drift-Adapter 같은 linear adapter 학습은 범위 밖

프로덕트가 되려면

  • API 기반 임베딩 모델 지원 (OpenAI, Cohere, Voyage)
  • 프로덕션 벡터 DB에서 직접 샘플링 (Pinecone, Weaviate 연동)
  • Drift-Adapter: 두 벡터 공간 사이의 linear mapping 학습으로 재인덱싱 없이 마이그레이션
  • GitHub Action / CI 플러그인으로 모델 업그레이드 PR에 자동 리포트 첨부
