카테고리: DevOps / Infrastructure Monitoring 스택: Python, FastAPI, SQLite, Chart.js, psutil 날짜: 2026-03-03

Background

솔로 개발자가 늘고 있다. 사이드 프로젝트든 인디해커든, 혼자서 프로덕션 인프라를 운영하는 사람이 많아졌다.

문제는 이 사람들이 엔터프라이즈급 인프라 도구와 아무 도구도 안 쓰는 것 사이에 끼어 있다는 거다.

  • Datadog, New Relic → 솔로 개발자에겐 과하고 비싸다
  • Uptime Kuma, Healthchecks.io → 각각 하나만 해결한다
  • 결국 3-4개 도구를 조합하거나, 아예 모니터링 없이 운영한다

"소규모 팀에 맞는 인프라 가시성"이 구조적으로 부재한 상황이다.

Pain Point

커뮤니티에서 반복적으로 나오는 세 가지 고통:

#출처SignalPain Point
1r/SideProject●●●○단일 리전 업타임 모니터가 네트워크 블립에도 새벽 3시 알림을 보낸다
2Hacker News●●●○크론잡이 겹쳐서 경고 없이 서버 메모리를 고갈시킨다
3r/webdev●●●○하루 3시간 쓰는 서버에 EC2 24/7을 띄워서 월 $2,100 낭비

공통 원인: 솔로 개발자에겐 인프라 전체를 한 눈에 볼 수 있는 가벼운 도구가 없다.

Solution

한 줄 요약: 서버 리소스 패턴을 자동 분석해서 "하루 N시간만 활성 → 서버리스 전환 시 월 $X 절감" 인사이트를 제공하는 셀프호스팅 대시보드

기존 도구와 다른 점

기존 도구하는 일안 하는 일
Uptime Kuma업타임 모니터링비용 분석, 크론 감시
Healthchecks.io크론 누락 감지중복 실행 감지, 비용 분석
Cronboard크론 충돌 감지 (베타)업타임, 비용 분석

→ 이 대시보드: 메트릭 수집 + 패턴 분석 + 비용 비교 + 업타임 + 크론을 하나의 경량 도구로 통합

  • Collection: psutil collects CPU/Memory/Network every 30s → stored in SQLite
  • Analysis: Active/Idle classification at 10% CPU threshold → daily active hours → Lambda cost estimation
  • Presentation: FastAPI + Chart.js single-page dashboard

대시보드 구성

다크 테마 2-컬럼 레이아웃:

  • 메인: CPU/Memory 시계열 → Active/Idle 세그먼트바 → 일별 활성 시간 → EC2 vs Lambda 비용 그리드
  • 사이드바: Uptime 상태 (●/● + 응답시간) · Cron Heartbeat 요약 (마지막 수신 + 횟수)

첫 실행 시 36시간 시뮬레이션 데이터 자동 생성 → 즉시 대시보드 확인 가능

Key Decisions & Lessons

1. FastAPI lifespan으로 별도 프로세스 없이 수집

  • asynccontextmanager로 서버 시작 시 메트릭 수집 태스크를 백그라운드로 실행
  • 별도 데몬이나 crontab 설정 없이 uvicorn server:app 하나로 전부 동작
  • 솔로 개발자에게 "실행 명령어 하나"는 채택 장벽을 크게 낮춤

2. Lambda 비용 모델 조정 — 셀프 크리틱에서 발견

  • 처음엔 100 req/hr + 128MB → Free Tier에 흡수돼서 Lambda 비용이 $0으로 나옴
  • 비현실적이라 5,000 req/hr + 256MB/500ms + Free Tier 제외로 상향
  • EC2 $7.59 → Lambda $2.33, 69.3% 절감 — 의미 있는 비교가 됨

3. 심의 점수와 범위 타협

  • 문제 진정성 3.7 / 프로토타입 적합성 2.7 / 신선도 2.7 / 학습 가치 3.7
  • 반대 의견: "업타임은 Uptime Kuma retry, 크론은 flock으로 이미 해결됨"
  • → 범위를 비용 분석에 집중, 업타임·크론은 통합 뷰 컨셉 시연 수준으로 축소

Results & Future

성과 (5/5 통과)

  • ✓ 시스템 메트릭 30초 간격 수집 → SQLite (4,300+ rows)
  • ✓ 활성/유휴 자동 분류 + "하루 N시간 활성" 산출
  • ✓ EC2 vs Lambda 비용 비교 + 자동 추천 메시지
  • ✓ 시계열 + 세그먼트 + 비용비교 통합 대시보드
  • ✓ 업타임 + 크론 하트비트 사이드 패널

한계

  • 비용 모델이 하드코딩 가격표 기반 — 실제 AWS API 연동은 미포함
  • 단일 서버 메트릭만 수집 — 다중 서버 지원 없음
  • 알림/노티피케이션 시스템 없음

프로덕트가 되려면

  • 실제 클라우드 API 연동 (AWS Cost Explorer, GCP Billing)
  • 멀티 서버 에이전트 + 중앙 집계
  • Slack/Discord 알림 통합
  • "서버리스 전환하면 이렇게 바꿔라"는 구체적 마이그레이션 가이드 생성
